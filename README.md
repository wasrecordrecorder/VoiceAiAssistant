# WebViewDA

WebViewDA is a desktop AI assistant for Windows built with C++, WebView and CMake.
The project combines voice control, text chat, local automation tools and a modern desktop interface into one assistant that can help with everyday PC control, coding tasks, file operations, web actions and long-running workflows.

The assistant supports voice input, push-to-talk mode, live transcription, text-to-speech output, a full text chat mode, memory storage, task management and tool-based actions. It is designed as a local desktop companion that can understand user requests, reason through steps, interact with files, run commands, open links, control media and work with the current screen context.

## Features

* Voice and text assistant modes
* Push-to-talk and configurable hotkeys
* Live speech transcription
* Text-to-speech response playback
* WebView-based modern desktop UI
* Dark theme interface
* Chat history and sidebar navigation
* File attachments and drag-and-drop support
* Memory system for persistent notes
* Task and todo management
* Tool execution for files, commands and system actions
* Web search support
* Screen reading mode for vision-capable models
* Floating always-on-top status widget
* Support for multiple AI providers and models
* Agent-style workflow with step tracking

## Goal

The goal of WebViewDA is to create a practical desktop AI assistant that feels useful outside the browser: it can listen, speak, remember context, control parts of the PC, help with projects and act as a real productivity layer over Windows.

## Tech Stack

* C++
* WebView
* CMake
* Windows
* Local/remote AI model providers
* Speech recognition
* Text-to-speech
