Настройки

Модель

Речь

Для длинной диктовки поставьте паузу от 1800 до 2500 миллисекунд. В режиме рации фраза отправляется после отпускания кнопки.

medium, large-v3 и turbo загружаются дольше и требуют больше памяти. Для русского текста выбирайте их только если компьютер справляется.

Агент

Максимум шагов теперь до двухсот пятидесяти шести. Режим Hermes Duo можно выбрать прямо в текстовом поле: Hermes_Coder готовит изменение, QA-Tester ищет регрессии.

Чтение проекта и безопасные статусы доступны сразу. Открытие, команды и удаление требуют подтверждения, пока вы явно не разрешите их без запросов.

Если включено, модель сможет запросить полный снимок экрана. Без второго флажка каждый снимок подтверждается вручную.

Память

Память хранится локально в Markdown и автоматически ограничивается по размеру. Менее важные старые записи удаляются первыми.
